# 离线改写的分片 Nucleus 采样与候选绑定

项目资料使用可独立读写的 JSON。Node.js 22.23.4 下运行 `npm ci --offline` 准备环境，然后运行 `npm run inspect` 检查合成数据字段，运行 `npm test` 校验样本引用及格式。

## 输入契约

权威 ID 及所属分片在 vocab 给出，未授权的复制位置不再映射到另一 token ID。正温度 T 时按 exp(logit/T) 的比例计算。排名按校正后 logit 下降、ID 递增，取最短非空前缀使全域质量达到 p。采样在前缀内重新归一化，u 属于 [0,1)，区间左闭右开。分片暂缺上界为有效未收到位置的 logit 上界，若证据不足可以等真实分片，不得把上界当实测值。随机输入由调用方 replay 值给出。余量只计运行时持有的分数、概率、候选及证明中间状态。

## 资料读取

样本位于 `inputs/session.json`，其中 `events` 是按到达顺序记下的操作，编号从零开始。request 的参数是编辑分支和选区版，shard 表示提供完整分片。draw 指随机流位置，take 与 retract 给出分支和选区版，edit 指新选区及版号。
